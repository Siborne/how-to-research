# 🎯 科研方向学习资料

> 🧭 [首页](../../README.md) › **科研方向学习资料**

本部分整理了一份面向入门者的「AI 科研方向」自学路线：从深度学习与 LLM 基础，到推理、Agent、神经符号学习等具体方向的文献阅读与代码实践，最后以一次完整汇报收尾。

> 📌 参考来源：本文档由 [LAMDA-NeSy/Lab-RoadMap](https://github.com/LAMDA-NeSy/Lab-RoadMap)（本科生科研入门学习指南）整理改写而来，已去除课题组专属信息，改为通用学习资料。

## 适合谁

- 已有一定机器学习 / 深度学习基础，想进一步入门 LLM / MLLM Reasoning、Agent、Neuro-Symbolic Learning 等科研方向的同学。
- 希望在 **6–8 周** 内，从「读懂论文」到「跑通一个方向的小实验」，并形成一次完整汇报。

## 学习目标

- **基础夯实**：掌握 AI、大模型、智能体基础知识，能自主检索并读懂前沿论文与代码。
- **领域认知**：理解大模型 / 多模态推理、AI Agent、神经符号学习的基本问题与研究范式。
- **科研素养**：建立「提出问题 → 文献检索 → 代码复现 → 实验分析」的完整科研闭环。

## 开始前的自测

建议先确认自己是否具备以下基础；不达标就按顺序学习，达标可以直接进入方向实践：

1. 了解提升大模型推理能力的常用后训练算法，如 SFT、GRPO。
2. 能加载某个开源大模型或调用闭源大模型 API，在某个评测数据上完成性能评估。
3. 了解智能体基础，能基于 ReAct 实现一个简单工具调用的 Agent。
