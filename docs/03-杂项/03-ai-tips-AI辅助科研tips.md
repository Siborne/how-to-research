## 快捷键

- **`!`** → 执行会话外的 shell 命令，输出会进入上下文
- **`@`** → 引用文件 / 路径 (带自动补全)
- **`#`** → 写记忆：把一条内容追加进 `CLAUDE.md`，不用打开文件
- **换行(不发送)：** `Command + J` 或 `Option + Enter`
- **`Command + U`**：清空当前输入行
- **`Command + R`**：搜索历史 prompt
- **`Command + V`**：粘贴截图
- **`Shift + Tab`** → 循环切换三种模式：
  - 普通：每次动手前询问
  - plan mode：只规划、不改文件；先规划后编码
  - auto-accept edits：自动接受编辑、连续执行
- `claude --dangerously-skip-permissions`：允许所有操作
- prompt 里写 `think` / `think hard` / `ultrathink` → 逐级提高推理预算
- **`Esc`** → 立刻打断当前动作(不退出会话)
- **双击 `Esc`**（= `/rewind`）→ 回退到之前某条消息
- **`/rewind`**（checkpoints）→ 把对话或代码文件回滚
  - 双击 Esc 回退对话；`/rewind` 能回滚代码文件
